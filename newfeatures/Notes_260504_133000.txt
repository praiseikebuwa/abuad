🧠 What you are building (correct definition)
You are building:
A unified AI Agent Engine for a social + messaging platform
Think of it as:
• One AI brain
• Many entry points (post, chat, comment)

⚙️ Core Architecture (clean and scalable)
1. Flutter App (frontend only)
Handles:
• Posts
• Chats
• Comments
• Sending “events” to backend
It does NOT run AI.
2. Node.js Backend (MAIN CONTROL CENTER)
This is where everything happens:
• Detects triggers (@AI, tags, mentions)
• Classifies context: 
• post comment
• chat message
• reply thread
• Sends request to AI models
• Stores responses
3. AI Engine (Open-source models)
You need 2 types of models:
🧠 TEXT MODEL (for replies)
Best open-source options:
✔ Mistral 7B (BEST CHOICE)
• Fast
• Lightweight
• Good reasoning
• Easy to host
✔ LLaMA 3 (strongest quality)
• More powerful
• Needs stronger GPU
✔ Gemma (Google)
• Balanced option
🎨 IMAGE GENERATION MODEL
✔ Stable Diffusion XL (SDXL)
• Industry standard
• Open-source
• Great quality images
You run it on:
• AWS GPU EC2 (g4dn / g5)
• OR DigitalOcean GPU droplet
🔁 SYSTEM FLOW (IMPORTANT)
📝 POST COMMENT FLOW
User posts content ↓ Another user comments "@AI explain this" ↓ Backend detects event type = POST_COMMENT ↓ AI text model generates response ↓ Backend writes reply UNDER that comment thread ↓ Flutter auto-updates UI 
💬 CHAT FLOW
User sends message "@AI help me" ↓ Backend detects CHAT context ↓ AI generates response ↓ Inserted into chat thread as AI message 
🎨 IMAGE GENERATION FLOW
User: "@AI generate a school logo" ↓ Backend detects image intent ↓ Send request to Stable Diffusion ↓ AI generates image ↓ Upload to S3 ↓ Return image URL into post/comment/chat 
🧠 KEY DESIGN RULE (VERY IMPORTANT)
You MUST route everything through an AI Event Router:
function routeEvent(event) { if (event.type === "comment" && event.text.includes("@AI")) { return "POST_REPLY"; } if (event.type === "chat" && event.text.includes("@AI")) { return "CHAT_REPLY"; } if (event.text.includes("generate image")) { return "IMAGE_GENERATION"; } }
